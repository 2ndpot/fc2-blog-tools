# fc2-blog-tools

Utility scripts and data for FC2 Blog.

FC2ブログ向けの小さなJavaScriptとデータ集です。

## editor-helper.js

FC2の記事編集画面に補助機能を追加します。

## music-embed.js

記事内のJSONから、YouTube動画と楽曲クレジットを生成します。

## waka.js

百人一首の歌番号をもとに、和歌・作者・出典を生成します。
仮名には自動的に `span.kana` を付与します。

## data/hyakunin-isshu.json

小倉百人一首100首のマスターデータです。
歌、作者、出典、出典番号、決まり字を収録しています。
